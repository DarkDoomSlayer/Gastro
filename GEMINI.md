# Reglas del Proyecto — GastroProyect (Morelosoft International Solutions)

## 1. Gestión de Documentos y Google Drive Oficial
- **Carpeta Oficial de Google Drive:**
  - URL: `https://drive.google.com/drive/folders/1BySk5NDtGTTPdJblN6ij5fQd4a3DDgOX?usp=sharing`
  - ID de Carpeta: `1BySk5NDtGTTPdJblN6ij5fQd4a3DDgOX`

- **Artefactos Clave Identificados en Google Drive:**
  - `Gastro-Agreement`: Acuerdo de alcance, propósito y exclusiones del sistema.
  - `Gastro-ProyectPlan`: Plan del proyecto bajo ISO/IEC 29110-5-1-1 y Scrum (CUs CU-01 a CU-09, roles, riesgos y calendario).
  - `Gastro_IterationPlan1.xlsx`: Plan de iteración 1 y control de Casos de Uso.

- **Protocolo de Lectura:**
  - Las consultas a Google Drive son estrictamente de solo lectura a menos que el usuario indique lo contrario explícitamente.
  - El usuario nunca debe descargar ni mover archivos manualmente; el agente gestiona las consultas de forma autónoma.

## 2. Estándar de Ingeniería y Calidad
- **Marco Metodológico:** ISO/IEC 29110-5-1-1:2025 para entidades muy pequeñas (VSEs) y Scrum.
- **Trazabilidad Obligatoria:** 100% de coherencia entre los Requerimientos del Acuerdo/Plan, el Modelo de Base de Datos, la Arquitectura de Software y el Código Fuente.
- **Entorno Contenerizado:** Toda la arquitectura debe ser ejecutable y reproducible mediante `docker-compose.yml`.
